# Kino Actions Documentation

## Overview

This document describes the available application actions in Kino. Actions are page-specific and can only be used on their respective pages.

## General Actions

|      Name      | Description                                        |
| :------------: | -------------------------------------------------- |
|  SettingsOpen  | Opens the settings screen                          |
|   CloseModal   | Closes the current modal                           |
|  LayoutToggle  | Toggles the content layout                         |
| RefreshContent | Refreshes only the current content                 |
|   RefreshAll   | Refreshes both the current content and collections |
|  SearchToggle  | Opens the search dialog                            |
|      Back      | Navigates back to the previous page                |
|    Forward     | Navigates forward to the next page                 |
|    WishNew     | Navigates to the wishlist page and opens the new wishlist dialog                |
|    SelectionStart     | Enters selection mode, adding clicked media to a new playlist                 |

## Player Actions

|       Name       | Description                                               |
| :--------------: | --------------------------------------------------------- |
|    PlayToggle    | Toggles Play/Pause                                        |
|     PlayNext     | Plays the next video                                      |
|   PlayPrevious   | Plays the previous video                                  |
| FullscreenToggle | Toggles full screen mode                                  |
|       Exit       | Exits either full screen mode or closes the current modal |
|     SeekBack     | Rewind video                                              |
|  SeekBackShift   | Rewind video                                              |
|    SeekFront     | Fast forward video                                        |
|  SeekFrontShift  | Fast forward video                                        |
|  VolumeIncrease  | Increases the volume                                      |
|  VolumeDecrease  | Decreases the volume                                      |
|    MuteToggle    | Toggles mute                                              |
|  SpeedIncrease   | Increase playback rate                                    |
|  SpeedDecrease   | Decrease playback rate                                    |
|    SpeedReset    | Reset playback rate                                       |
|   VideoConfig    | Opens the video configuration menu                        |
|   VideoComment   | Opens the video comment dialog                            |
|   VideoCommentNew   | Starts a new comment on the current playback           |
| SubtitlesToggle  | Toggles video subtitles                                   |
|       Add        | Opens the add to collection dialog                        |
|    CloseView     | Closes the current modal                                  |
|       Back       | Exits the video player                                    |
|  PlaylistToggle  | Toggles the playlist view                                 |

## Settings Action

|  Name  | Description                                    |
| :----: | ---------------------------------------------- |
| Cancel | Discards changes and exits the settings screen |
|   Up   | Navigates to the next sub-menu                 |
|  Down  | Navigates to the previous sub-menu             |
